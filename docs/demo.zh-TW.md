# FeatherMD 羽讀

輕一點，讀更多。

## 留白給閱讀

這是一個使用 **Rust** 編寫的原生 Markdown 閱讀器。沒有瀏覽器核心，也不必等整份檔案載入。

- **快速首屏**：每次只讀取附近的 128 KiB
- **專注閱讀**：12 款主題，含書本與古籍
- **隨身攜帶**：一個 EXE，無須安裝執行環境
- [x] 简体中文、繁體中文、English、日本語介面
- [x] 背景搜尋與百分比跳轉

> 檔案可以很大，閱讀器應該很輕。

## 從這裡開始

按 `Ctrl+O` 開啟文件，按 `Ctrl+F` 搜尋。滑鼠移到程式碼區塊上，右上角可以一鍵複製。

```rust
fn main() {
    println!("Hello, FeatherMD!");
}
```

**安全的預設設定**：預設不連網，不執行文件內的 HTML 或指令碼。
