# The details in a document

Tables, lists and inline code, with room for each to breathe.

## Everyday shortcuts

| Action | Shortcut | Purpose |
| :--- | :--- | :--- |
| Open a document | Ctrl+O | Choose a local file |
| Find text | Ctrl+F | Search the document |
| Toggle outline | Ctrl+B | Show or hide chapters |
| External editor | Ctrl+E | Use your chosen editor |
| Refresh | F5 | Read the file again |
