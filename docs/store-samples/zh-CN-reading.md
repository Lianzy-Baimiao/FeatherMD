# 把注意力留给阅读

打开一份项目说明、一篇笔记，或是还没读完的技术文档。
**FeatherMD 羽读**只做一件事：让本机 Markdown 文件读起来更舒服。

## 从这里开始

- 用左侧目录找到想读的章节
- 按 `Ctrl+F` 搜索，按 `Ctrl+B` 收起目录
- 随时切换预览与源码，不改动原文件

> 少一点界面，多一点内容。

## 一小段代码

```rust
fn main() {
    let message = "Hello, FeatherMD!";
    println!("{message}");
}
```

## 按自己的习惯读

选择浅色或深色外观，调整字体和字号。需要修改时，交给你选择的编辑器。
