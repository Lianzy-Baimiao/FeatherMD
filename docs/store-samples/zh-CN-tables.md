## 常用快捷键

| 操作 | 快捷键 | 用途 |
| :--- | :--- | :--- |
| 打开文档 | Ctrl+O | 选择本机文件 |
| 搜索文字 | Ctrl+F | 在文档中查找 |
| 显示目录 | Ctrl+B | 展开或收起章节 |
| 外部编辑 | Ctrl+E | 交给选定的编辑器 |
| 刷新文档 | F5 | 重新读取当前文件 |
