# A little more room to read

Open a project README, a page of notes, or the technical document you left halfway through.
**FeatherMD** keeps the focus on reading local Markdown files.

## Start here

- Find a chapter in the outline
- Press `Ctrl+F` to search or `Ctrl+B` to hide the outline
- Switch between preview and source without changing the file

> Less interface. More of the document.

## A small piece of code

```rust
fn main() {
    let message = "Hello, FeatherMD!";
    println!("{message}");
}
```

## Read your way

Choose a light or dark appearance and adjust the reading font. When it is time to edit, hand the file to your chosen editor.
