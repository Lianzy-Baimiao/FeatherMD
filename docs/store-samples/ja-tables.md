# 文書の細部まで

表、リスト、インラインコードを、すっきり読みやすく。

## よく使うショートカット

| 操作 | キー | 用途 |
| :--- | :--- | :--- |
| 文書を開く | Ctrl+O | ローカルファイルを選択 |
| 文字を検索 | Ctrl+F | 文書内を検索 |
| 目次を切り替え | Ctrl+B | 章の一覧を表示・非表示 |
| 外部エディター | Ctrl+E | 選択したエディターで開く |
| 再読み込み | F5 | 現在のファイルを読み直す |

## 今日の読書リスト

- [x] プロジェクトの概要を読む
- [x] 設定の例を見つける
- [ ] 自分のメモを整理する

## 画像の表示は自分で選ぶ

ローカル画像は初期設定では非表示です。設定から有効にできます。ネット上の画像は一枚ずつクリックして確認する必要があり、自動ではダウンロードしません。
