# 文件裡的細節

表格、清單與行內程式碼，放在一起也清清楚楚。

## 常用快捷鍵

| 操作 | 快捷鍵 | 用途 |
| :--- | :--- | :--- |
| 開啟文件 | Ctrl+O | 選擇本機檔案 |
| 搜尋文字 | Ctrl+F | 在文件中尋找 |
| 顯示目錄 | Ctrl+B | 展開或收起章節 |
| 外部編輯 | Ctrl+E | 交給選定的編輯器 |
| 重新整理 | F5 | 重新讀取目前檔案 |
