# 読むことに集中する

プロジェクトの README、メモ、読みかけの技術文書を開く。
**FeatherMD** は、ローカルの Markdown ファイルを読むためのアプリです。

## ここから始める

- 左の目次から読みたい章へ移動
- `Ctrl+F` で検索、`Ctrl+B` で目次を非表示
- 元のファイルを変更せず、プレビューとソースを切り替え

> 文書そのものに、もっと余白を。

## 小さなコード例

```rust
fn main() {
    let message = "Hello, FeatherMD!";
    println!("{message}");
}
```

## 自分に合った読み方で

明るい外観と暗い外観を選び、フォントと文字サイズを調整できます。編集が必要なときは、選択したエディターで開けます。
