# 把注意力留給閱讀

打開一份專案說明、一篇筆記，或是還沒讀完的技術文件。
**FeatherMD 羽讀**專注於一件事：讓本機 Markdown 檔案讀起來更舒服。

## 從這裡開始

- 用左側目錄找到想讀的章節
- 按 `Ctrl+F` 搜尋，按 `Ctrl+B` 收起目錄
- 隨時切換預覽與原始碼，不改動原始檔案

> 少一點介面，多一點內容。

## 一小段程式碼

```rust
fn main() {
    let message = "Hello, FeatherMD!";
    println!("{message}");
}
```

## 按自己的習慣讀

選擇淺色或深色外觀，調整字型與字級。需要修改時，交給你選擇的編輯器。
