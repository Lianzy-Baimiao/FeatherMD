# FeatherMD

軽く、もっと読む。

## 読むための余白

**Rust** で書かれたネイティブの Markdown リーダーです。ブラウザーエンジンはなく、ファイル全体の読み込みも待ちません。

- **すぐに表示**：一度に読むのは近くの 128 KiB だけ
- **読書に集中**：ブック、古書、夜向けを含む 20 種類のスキン
- **持ち運べる**：EXE ひとつ、ランタイムのインストール不要
- [x] 简体中文、繁體中文、English、日本語の画面
- [x] バックグラウンド検索とパーセント位置への移動

> ファイルは大きくても、リーダーは軽く。

## はじめに

`Ctrl+O` でドキュメントを開き、`Ctrl+F` で検索します。コードブロックにマウスを重ねると、右上のボタンでコピーできます。

```rust
fn main() {
    println!("Hello, FeatherMD!");
}
```

**安全な既定値**：既定でオフライン。ドキュメント内の HTML タグは体裁のためだけに使い、スクリプトは実行しません。

[FeatherMD プロジェクトへ](https://github.com/Lianzy-Baimiao/FeatherMD)
