# FeatherMD 羽读

轻一点，读更多。

## 留白给阅读

这是一个使用 **Rust** 编写的原生 Markdown 阅读器。没有浏览器内核，也不必等整份文件载入。

- **快速首屏**：每次只读取附近的 128 KiB
- **专注阅读**：浅色、深色与护眼主题
- **随身携带**：一个 EXE，无需安装运行时
- [x] 中文、英文与 emoji 😀
- [x] 后台搜索与百分比跳转

> 文件可以很大，阅读器应该很轻。

## 从这里开始

按 `Ctrl+O` 打开文档，按 `Ctrl+F` 搜索。

```rust
fn main() {
    println!("Hello, FeatherMD!");
}
```

**安全的默认设置**：完全离线，不执行文档内的 HTML 或脚本。

[访问 FeatherMD 项目](https://github.com/Lianzy-Baimiao/FeatherMD)
