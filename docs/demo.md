# FeatherMD 羽读

轻一点，读更多。

## 留白给阅读

这是一个使用 **Rust** 编写的原生 Markdown 阅读器。没有浏览器内核，也不必等整份文件载入。

- **快速首屏**：每次只读取附近的 128 KiB
- **专注阅读**：20 款皮肤，含书本、古籍与夜读
- **随身携带**：一个 EXE，无需安装运行时
- [x] 简体中文、繁體中文、English、日本語界面
- [x] 后台搜索与百分比跳转

> 文件可以很大，阅读器应该很轻。

## 从这里开始

按 `Ctrl+O` 打开文档，按 `Ctrl+F` 搜索。鼠标移到代码块上，右上角可以一键复制。

```rust
fn main() {
    println!("Hello, FeatherMD!");
}
```

**安全的默认设置**：默认不联网；文档内的 HTML 标签只用于排版，脚本不会执行。

[访问 FeatherMD 项目](https://github.com/Lianzy-Baimiao/FeatherMD)
