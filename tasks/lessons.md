# 项目经验

作者：lianzy
最后修改人：lianzy

## 2026-10-12 用户反馈：滚动条不可用，原生边框不符合要求，界面观感差

- 键盘翻页通过不代表滚动条可用；需要验证拖动滑块、轨道点击、滚轮、横向滚动和长文件定位的实际窗口路径。
- 自绘正文必须与窗口标题栏、边框、控件和状态栏保持统一，不能仅以替换颜色作为界面完成标准。
- 交付界面修改前应检查真实绘制截图、浅深主题及窄窗口，并明确区分脚本消息测试与真实鼠标操作。
- 启用 CS_DBLCLKS 的自绘窗口必须将 WM_LBUTTONDBLCLK 纳入控件按下路径；否则先点击再拖动会失败，单次 WM_LBUTTONDOWN 测试检测不到。
- 调用 DefWindowProc 进入系统移动/缩放循环前释放应用状态借用；WM_CANCELMODE 需要明确释放鼠标捕获。

## 2026-10-12 用户修正：需要可隐藏目录，独立工具栏占空间

- 阅读器优先给内容让位，避免标题栏下再堆一整行低频操作；把主要操作合入标题栏，其余收进菜单。
- 文档阅读导航应提供可折叠目录；标题提取必须后台、有界、可取消，不能让打开文件等待全文扫描。

## 2026-10-12 用户修正：目录开关重复

- 用户指出重复控件时，要结合控件归属理解反馈，不能默认应用标题栏的入口应该保留。
- 目录开关属于文档导航：展开时放在目录标题旁，收起后在内容左边缘提供恢复入口；不要同时在应用标题栏放第二个按钮。
- 界面预览必须来自最终构建；发布前检查展开、隐藏和窄窗口状态的控件数量与位置。

## 2026-10-12 用户修正：源码和明暗切换不能藏在更多中

- 高频阅读模式和明暗主题放在顶部，以可见状态的切换控件表达；更多只承载低频设置。
- 跟随系统是独立主题偏好，不能仅在启动时复制一次明暗值；系统变化需要实时刷新，手动选择要保留。

## 2026-10-12 用户测试：默认应用清单找不到 FeatherMD

- 注册表条目测试通过不等于 Windows 外壳清单可用；文件关联必须验证真实设置页与打开方式的可发现性。
- 先检查实际注册路径和运行的 EXE，再区分按应用列表、按扩展名选择器、右键打开方式三条路径；不能把启动设置当成功。

## 2026-10-12 顶部主题开关的阅读位置回归

- 只改变颜色时不要调用通用的重新排版路径：物理行内可能有很多换行位置，单独保存字节偏移会把阅读位置拉回段首。
- 检查用户眼前的交互状态，而不只是配置已保存；用 4096 字节以下的单段落验证切换前后的换行序号。
- 原生消息测试在缩放显示器上要和目标窗口使用一致的物理坐标，避免把测试进程的 DPI 虚拟化误判为产品拖动失败。

## 2026-10-12 用户反馈：关于窗口的系统弹窗外观太旧

- 关于窗口也要沿用阅读器的字体、留白和主题，不应为了原生而直接暴露默认 Task Dialog 外观；保持真正原生的键盘控件，并做一致的视觉设计。
- BS_OWNERDRAW 卡片需要验证 Tab 后 Enter 的实际行为，不能只测 BM_CLICK；默认对话框管理器可能把 Enter 交给默认“返回阅读”按钮。
- 隐藏窗口 PrintWindow 返回成功也可能全黑；复用进程内截图并断言背景像素，浅色和深色都要目视检查。

- 2026-10-12：用户说“首页上面 / 上面的 UI”时，先对齐主窗口顶部，而不是沿用上一项关于对话框的范围。顶部用紧凑图标和单入口主题选择，不再堆三段主题文字按钮；保留可发现的提示与快捷键。

## 2026-10-12 用户反馈：图标锯齿、需要自定义字体

- 自绘不等于精致；小图标不能直接用未抗锯齿的整数折线近似曲线。使用原生 GDI+ 矢量、圆端描边，检查原尺寸和最近邻放大截图，不用缩略图掩盖锯齿。
- 阅读字体与 UI 字体分离；测量和绘制必须用同一字体缓存，代码保留等宽。字体设置应有实时预览、取消草稿和持久化，不只是操作系统字体选择框。
- 原生跨进程测试用 WM_SETTEXT/WM_GETTEXT 操作 EDIT 内容，不能依赖 SetWindowText/GetWindowText 的远程标题行为；复合控件截图需要验证实际文字，而不只判断截图成功。

## 2026-10-13 右键编辑、皮肤透明度与更矮标题栏

- 缩小图标时，非整数描边会横跨两行像素而发虚；描边取半像素、中心对齐像素网格，矩形图标坐标取整，曲线保留抗锯齿。用 96/120/144 DPI 截图放大检查，而不只看一种缩放。
- 皮肤配色先用对比度脚本计算，再出图；已有配色不达标（护眼次要文字 4.24:1）也要指出并修正。
- Windows PowerShell 5.1：Set-Content -Encoding utf8 会写 BOM，读取 INI 必须容忍 BOM；含中文的 .ps1 需要 UTF-8 BOM 才能被 5.1 正确解析。PowerShell 的 -match 不区分大小写，解析测试结果用 -cmatch。
- 验证视觉结论前先验证实验本身：固定窗口位置、确认参数确实生效、与旧版逐字节对比。DWM 边框色在本机无可见差别，就恢复原样，不把无效改动写成改进。
- 弹出菜单和模态对话框前释放 App 借用；跨进程可以用 MN_GETHMENU 读取真实菜单文字，并向菜单窗口投递方向键/回车完成选择。

## 2026-10-12 用户反馈：目录高亮不跟随点击

- 目录当前项不能只由顶行位置推导：文末或整页可见时跳转会被 clamp，所点标题无法成为顶行。用户点击是明确意图，应保留到阅读位置再次变化为止。
- 导航回归要覆盖短章节、多标题同屏和文末场景，并直接断言高亮索引，而不只断言字节偏移。
