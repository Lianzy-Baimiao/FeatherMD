# FeatherMD contributor instructions

- Keep the Windows GUI native and dependency-light. No browser engine, network fetching, or full-file allocation. Sole exception: the opt-in update check (src/updater.rs) — one HTTPS GET of the public GitHub "latest release" record via system WinHTTP, off by default, at most daily when enabled, manual otherwise. It must never download, install or upload anything; keep any test URL override loopback-only.
- File reading and searching must remain off the UI thread. Preserve the 128 KiB read window, 4096-byte long-line segments, 2048-line layout limit, and cancellable 256 KiB search chunks.
- Do not use mmap: externally edited/truncated files must stay safe.
- Never silently take default associations or write UserChoice. Registration is opt-in, per-user, and must preserve other applications.
- Do not execute Markdown HTML, scripts, local links, or remote images. HTML tags only shape text (src/html.rs); script/style/embedded content stays hidden. External HTTP(S) links need a user confirmation.
- Images are off by default (Settings → Reading → Show images). When on, only local raster files are read (src/image.rs rules, src/ui/pictures.rs loader): drive-letter paths on fixed/removable drives, no links, junctions, network drives, shares, devices or online-only cloud files; bounded size, pixels and cache; decoded off the UI thread, content-sniffed before any decoder sees it. Never fetch remote images.
- Tests before release: cargo fmt --check; cargo clippy --all-targets -- -D warnings; cargo test; cargo build --release; scripts/ui-smoke.ps1; scripts/navigation-smoke.ps1 (headings and wrapped shapes); scripts/about-smoke.ps1, scripts/typography-smoke.ps1, scripts/settings-smoke.ps1, scripts/update-smoke.ps1, scripts/table-smoke.ps1 and scripts/image-smoke.ps1 (light and dark); scripts/editor-smoke.ps1; scripts/i18n-smoke.ps1 (all interface languages, no clipped text). Build the stand-ins first: cargo build --release --example editor_probe --example update_server.
- "Edit" only hands the document path to the user's chosen editor as one quoted argument. Never write documents, file associations or default apps from it.
- Read docs/PROGRESS.md before continuing. Record precise evidence and limitations; distinguish warm-cache parsing, GUI first layout, real files, and sparse files.
- Do not publish ignored fixtures, local settings, local build environment scripts, or other workspace data. Never force-push.
- Use MSVC for distributable Windows binaries with static CRT. The local host has a GNU default toolchain; use cargo +stable-x86_64-pc-windows-msvc. If needed, source ignored target/dev-env.ps1 on this development machine. Do not commit machine-specific paths.
